LLM Mechanics

Understanding the two distinct phases of Large Language Model inference.

The "Prefill" Phase

When you hit enter, the model must read your entire input at once. This is parallelizable.

  • The GPU processes all tokens simultaneously.
  • It calculates the KV Cache (Key-Value) for every token.
  • Speed is measured in Tokens per Second (TPS) during prefill.

The "Decoding" Phase

Now, the model predicts one token at a time. This is sequential.

  • Each new token depends on all previous tokens.
  • It cannot be parallelized; it's a loop.
  • This is where you see the "typing" effect in ChatGPT.

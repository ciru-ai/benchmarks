What the matrix shows

ROCmFP4 on TheRock is the overall throughput winner. It leads both prompt processing at 320.00 tok/s and generation at 38.24 tok/s, while posting the lowest measured TTFP at 11.02 seconds.

The backend winner depends on the quantization path. Vulkan leads generation for BF16, Q8, Q5, and Q4; TheRock leads Q6, ROCmFP4, and vanilla UltraQuality. TheRock consistently processes this prompt faster, but that PP advantage does not automatically translate into faster token generation.

The corrected UltraQuality row is built from the same vanilla Unsloth BF16 source as the rest of the matrix using the ranked leave-32 ROCmFPX/Q6_K-splice policy. No fine-tuned derivative weights are included.

Method and scope

Matched serving controls

  • Same runtime source commit: 5d04ce30c.
  • Vulkan0 via RADV versus ROCm0 via TheRock 7.15.
  • One slot, full GPU offload, flash attention, 8K server context.
  • MTP cap 6 except ROCmFP4 cap 4; backend draft sampling disabled.

Request and limitations

  • The standard 4K fixture tokenized to 3,524 prompt tokens.
  • Exactly 128 generated tokens, prompt cache disabled, temperature 0.
  • One served-API measurement per cell; these are not multi-run averages.
  • Results characterize this Strix Halo host and these exact builds.
UltraQuality naming note. The vanilla artifact applies the UltraQuality tensor policy but omits the extra multimodal payload present in the earlier public 7.61-BPW fine-tuned artifact. It is therefore labeled simply ROCmFPX UltraQuality, without claiming the fine-tuned model identity or exact file-wide BPW.

01 / The study

What these numbers mean

A focused local regression panel. Useful for finding strengths and failure modes, with important limits on cross-model comparisons.

The panel

54 selected cases, four families

FAST54 is the reduced selection from the 95-case Contested Quality Suite. It tests 50 contested cases plus four frontier cases. These are selected diagnostic questions, not the full parent benchmarks.

Read before comparing

Counts are not a leaderboard

Models used different physical contexts, hardware, concurrency and—in some cases—different scorers or eligible questions. A result shown as 9/15 does not cover the same 17 cases as 15/17. No missing or capped answer is quietly converted into a wrong answer.

Publisher-setting runs use each model’s own scenario recipe. Historical nonthinking runs appear separately and are not recommended-setting comparisons.

06 / Reproduce

Run FAST54 yourself.

The public Contested Quality Suite includes the selected inputs, dependencies and grader sources. Follow its README for current requirements and protocol limits.

Linux · Python 3.11+ · uv · Bubblewrap

Start an OpenAI-compatible model server

git clone https://github.com/ciru-ai/contested-quality-suite.git
cd contested-quality-suite
./benchmark check
./benchmark --endpoint http://127.0.0.1:8080/v1 --model main --label my-model

Use the model ID advertised by your server. ./benchmark --all selects the full 95-case panel and requires the additional dependencies documented in the repository.

Protocol matters

Inspect actual model requests

The public default suite does not automatically apply a publisher’s recommended sampler across components. A custom sampling overlay is a different protocol and must retain its settings and grader revision. The public ARC driver’s 256-token cap does not record finish reasons, so inspect server-side telemetry before interpreting a miss.

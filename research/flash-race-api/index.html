08METHODS & DATA

Go deeper into the measurements.

The headline views use the selected results throughout. Expand a panel’s settings or download the measurements behind the charts.

How to read the race

The two-run mean averages each task’s measured duration and pass count. Run 1 and Run 2 show their recorded timelines. At 1×, one playback second equals one measured second. Faster modes compress the clock. Checkpoint lights use the task verifier’s verdict.

What the speed tests measure

The depth sweep processes 512, 2,048, or 4,096 new tokens at six context depths, measuring how quickly the new input is processed. Cold prefill reads five complete input lengths. HE0–9 uses ten code prompts with thinking off and natural response completion.

Scores and timing

Hermes averages both 20-task runs, including tool execution and verification in case wall time. The tool gauntlet awards up to two points per scenario. Numerical fidelity compares 2,048 selected positions against the full reference vocabulary.

Interactive charts

Python and pyecharts generate the charts. Focused axes reveal small differences; “Show zero” expands the scale. Prefill and decode appear side by side. The three prefill depth charts share one scale. Exact values stay visible and every model keeps the same color across the page.
